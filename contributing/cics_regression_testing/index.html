    zCics Sequential Terminal Regression Testing

    Note: This document was generated by Cursor AI.

    How the Regression Run Works

    When you run cics\bat\Z390RT.BAT:

    1. It copies Z390RT.INI → Z390CICS.INI with SEQ_TERM=YES.
    2. That disables normal local terminals and starts one sequential terminal SQ01 with no initial transid.
    3. Z390KCP opens cics\seq\SEQI0001.TXT for input and cics\seq\SEQO0001.TXT for output.
    4. Each TGET from application code reads the next CRLF-terminated record from the current SEQI file.
    5. Each TPUT writes a CRLF-terminated record to SEQO0001.TXT.
    6. On end-of-file, LCL0402 closes the file, increments the number (0001 → 0002 → ...), and opens the next SEQI file.
    7. When input is exhausted, the terminal requests shutdown.

    Key files

    File Role
    cics\seq\SEQDOC.TXT Authoritative human summary of each stream
    cics\seq\SEQInnnn.TXT Input byte streams (TGET replay)
    cics\seq\SEQCnnnn.TXT Golden output streams for comparison
    cics\seq\SEQO0001.TXT Output from a regression run
    cics\bat\Z390CMPG.BAT Compares SEQC files against SEQO0001.TXT
    cics\bat\Z390TRC.BAT Capture mode (SEQ_TERM=TRACE)
    cics\bat\Z390SEQG.BAT Extracts .TRE trace → SEQI/SEQC files
    cics\seq\SEQISHUT.TXT Sample shutdown stream (CEMT P SHUT)

    How to Read a SEQI Record

    Each record is one simulated 3270 keystroke/data submission:

    Byte(s) Meaning
    1 AID — 7D=ENTER, 6D=CLEAR, F1-F9=PF1-PF9, 7A-7C=PF10-PF12, C1-C6=PF13-PF18
    2-3 Cursor position (3270 address, EBCDIC-encoded)
    4+ Field data (EBCDIC text, map fields, CEBR commands, etc.)

    Records are separated by 0D 0A (CRLF). Decode field data as EBCDIC cp037.

    Starting a transaction from a blank screen: 

    ENTER + cursor + 4-char TRANSID

    Example from SEQI0001.TXT: 7D 40 C4 C1 C1 C1 C1 → ENTER, then transid AAAA.

    CLEAR (6D) ends a transaction and returns to an empty screen.

    For CEBR: 

    ENTER + cursor + "CEBR" + optional argument(s)

    e.g. Icebr MYQUEUE1, Icebr x'01cb458f'.

    AID reference: AIDINDEX table in cics\LCL0402.MLC.

    SEQC Comparator Coverage

    Only these streams currently have golden SEQC files for Z390CMPG in wrk_rt:

    0001–0011, 0017–0024, 0028

    Streams 0012–0016, 0025–0027, 0029–0031 have input (SEQI) but no SEQC golden output.

    Practical Decoding Tips

    1. Records are separated by 0D 0A (CRLF).
    2. Decode bytes as EBCDIC cp037 (not ASCII).
    3. Byte 1 is the AID; see AIDINDEX in cics\LCL0402.MLC.
    4. Cross-check against SEQDOC.TXT and the matching test program (TESTBED*, TESTBMS1, etc.).
